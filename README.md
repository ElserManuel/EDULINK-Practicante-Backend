# EDULINK-Practicante-Backend

EVALUACIÓN

Crear una aplicación web en php con laravel que tenga las siguientes características:
- Un login (es permitido usar Breeze).
- El ID debe ser un UUID.
- Debe tener un crud de 4 campos como mínimo (aparte del ID).
- Considerar que el crud soportará más de 100 registros, por lo tanto la tabla html donde se listen los datos registrados deben usar paginación (se permite usar la paginación nativa de laravel). Usar ajax para una interacción más sencilla por parte del usuario final.
- Debe permitir exportar a excel los datos registrados.
- Usar un modal para el registro y modificación de datos.
- Puedes usar MySQL con SGBD.
- Está permitido usar las librerías que consideren necesarias.
 Se calificará:
- Calidad de código
